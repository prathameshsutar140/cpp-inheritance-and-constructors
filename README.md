# cpp-inheritance-and-constructors
A collection of Turbo C++ programs demonstrating core Object-Oriented Programming (OOP) concepts, including class constructors, single inheritance, and multilevel inheritance.

# C++ Object-Oriented Programming (OOP) Practicals

This repository contains basic Turbo C++ practical programs covering core Object-Oriented Programming (OOP) concepts, including class constructors, single inheritance, and multilevel inheritance[cite: 1, 3, 7].

## Included Programs

### 1. Constructors and Default Initialization
Demonstrates C++ class constructors used to initialize default values for object members[cite: 5, 7].
* **Files:** `PR10EX1.CPP`, `PR10EX2.CPP`, `PR10PR1.CPP`[cite: 5, 6, 7]
* **Key Concepts:** Default constructors, `strcpy` initialization, and member variable assignment[cite: 5, 7].

### 2. Single Inheritance Examples
Demonstrates base classes extended by a single derived class to share properties[cite: 1, 2, 4].
* **Files:** `PR11EX1.CPP`, `PR11EX2.CPP`, `PR11PR1.CPP`[cite: 1, 2, 4]
* **Key Concepts:** Single-level class extension (`furniture` -> `table`, `Emp` -> `salary`, `Stud` -> `Mark`)[cite: 1, 2, 4].

### 3. Multilevel Inheritance Examples
Demonstrates a multi-tier class hierarchy where a derived class inherits from an intermediate derived class[cite: 3].
* **File:** `PR11P2.CPP`[cite: 3]
* **Key Concepts:** Chain inheritance (`Person` -> `Emp` -> `Prg`)[cite: 3].

## Environment & Requirements
* **Compiler:** Turbo C++ / Borland C++[cite: 1, 2, 3, 4, 5, 6, 7]
* **Headers Used:** `<iostream.h>`, `<conio.h>`, `<string.h>`[cite: 1, 5]
